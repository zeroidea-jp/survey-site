## こんな時に {#when}

{{< feature-grid >}}
{{< feature wsicon="wifi" title="使う予定の無線が、現場で使えるか知りたい" headingLevel="h3" >}}**遠隔操作の装置**、**AMR / AGV** などの導入前に現場の電波を測り、無線の方式や機種を決める根拠にします。{{< /feature >}}
{{< feature wsicon="network" title="現場の他社製品と、電波が競合しないか確かめたい" headingLevel="h3" >}}現場で動いている他社の装置や無線機器が使う帯域を測り、自社製品の無線と干渉しないかを確かめます。{{< /feature >}}
{{< feature wsicon="clock" title="導入まで日がないが、念のため測っておきたい" headingLevel="h3" >}}現地で測ってその場で解析し、翌日までに報告します。まず試しに、という場合もお受けします。{{< /feature >}}
{{< /feature-grid >}}

## 調査の内容 {#method}

{{< feature-grid variant="tile" >}}
{{< feature wsicon="chart" title="使う帯域の混み具合を測る" headingLevel="h3" >}}受信専用の計測器で、導入予定の無線が使う帯域に、いつ・どのくらい電波があるかを現地で記録します。{{< /feature >}}
{{< feature wsicon="flag" title="妨害電波の有無を確かめる" headingLevel="h3" >}}周囲の設備や他の無線からの干渉を、時間帯を変えて確かめます。{{< /feature >}}
{{< feature wsicon="report" title="導入前に分かる注意点を報告する" headingLevel="h3" >}}チャンネルや設置位置の選び方など、導入前に打てる手を A4 数枚の報告書にまとめます。{{< /feature >}}
{{< /feature-grid >}}

**特徴**: 電波は目に見えず、導入してから分かることが多い項目です。先に測っておくと、無線の方式や設置位置を根拠をもって決められます。

**体制**: 物理 (電磁波)・ネットワーク系のフィールドエンジニアが計画から現地、報告までを担当します。

**報告書のイメージ**: [報告書の見本 (PDF、A4 7 ページ)](files/survey_report_sample_v0.1.pdf) — 実際の計測データをもとに、報告の形式をつかんでいただくための参考資料です。

{{< /steps >}}

## よくある質問 {#faq}

{{< accordion >}}
{{< accordionItem title="どんな無線が対象ですか" >}}
70 MHz〜6 GHz の範囲 (ローカル 5G / LTE の sub-6、Wi-Fi 5 GHz / 2.4 GHz、サブギガ帯、400 MHz 帯・150 MHz 帯の業務無線を含みます)。
{{< /accordionItem >}}
{{< accordionItem title="計測の結果、装置側のネットワークに踏み込んだ調査が必要になったら" >}}
周辺の電波の計測だけでは原因が絞り込めず、装置側のネットワークや機器の挙動まで調べる必要が出てきた場合は、改めてご相談いただかなくても、そのまま続けて調査をお受けできます。追加の調査は **+25 万円** を目安にご案内します。弊社の関連サービス [whystop](https://whystop.zeroidea.co.jp/) (稼働中の装置の「止まる・途切れる」の原因調査、基準額 50 万円) との差額で、サイトサーベイの料金はそのまま充当します。
{{< /accordionItem >}}
{{< accordionItem title="導入後の装置でも調査できますか" >}}
導入後の「止まる・途切れる」の原因調査は、装置側も含めて調べる関連サービス [whystop](https://whystop.zeroidea.co.jp/) へ。周囲の電波の調査だけをご希望の場合は、導入後でも同じ料金でお受けします。
{{< /accordionItem >}}
{{< accordionItem title="守秘はどうなりますか" >}}
現場の情報、図面、計画の内容は調査の目的以外に使いません。守秘契約の雛形を用意しています。
{{< /accordionItem >}}
{{< accordionItem title="事前に用意するものは" >}}
導入予定の装置・無線の概要 (分かる範囲)、設置場所の図面か写真、立入手続き、受信専用の計測機器の持ち込み許可。
{{< /accordionItem >}}
{{< /accordion >}}
